Site audit — the reading floor, measured

Loads every page of site/ into a frame at a chosen width and measures every rendered text node: its computed size in pixels, and its true contrast against the background actually painted behind it, composited up the tree. It also flags any block that scrolls sideways while the page still has width to spare.

The rules are not this project's invention — they are pinned by StzZui's interface constitution, and this tool is a port of the measurement half of its own audit: rule 105 (the legibility floor — 16 px, 4.5:1), rule 107 (hierarchy is not miniaturization) and rule 114 (room before scrollbars). Nothing leaves the browser; no dependencies.

The data application (playground/ledger.html) is not in this list: it links the site's stylesheet as ../style.css, which resolves in the deployed layout — where the site is at / and the Playground at /playground/ — but not in the repository, where the two are siblings. Auditing it here would measure the missing stylesheet rather than the page. Check it against a deployed copy.

Serve the repository root and open this file, e.g. python -m http.server 8399 then localhost:8399/tests/site-audit.html. Check the widths that matter: a phone (375), a tablet (768), the point just above and below the menu's breakpoint (1023 / 1024), and a desktop (1440).

Press “Measure the site”.
