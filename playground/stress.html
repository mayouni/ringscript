Ring vs JavaScript, side by side

The question: can Ring — a language with no browser runtime of its own — do a real data job inside a web page? The only honest way to answer is to give the same job to something that obviously can, and show both results.

Ring 1.27 The real Ring VM, compiled to WebAssembly, running in this tab. The code it runs is stress.ring — plain Ring, nothing browser-specific.
JavaScript The browser's own engine, doing the same seven tasks the same way, in the script on this page. Its answers are the yardstick.
The job — a tontine ledger. A savings circle: members put money into numbered rounds. Given a list of deposits from an API, work out what came in, from whom, in which round, who leads — and reject anything that breaks the rule amount must be greater than 0.

Both players get byte-identical input. Every answer is compared; a single mismatch fails the run.
