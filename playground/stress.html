Tontine ledger

A savings circle under load: members, rounds, deposits. The whole computation — validate, aggregate, rank, report — is a page of ordinary Ring, running in this tab. Every number it produces is re-computed in JavaScript and compared, so this is a correctness test that happens to be timed.

On a phone start at 20,000. The first run also pays for growing the VM's heap to hold the decoded records — that cost is shown separately, because a page feels it once and never again.
